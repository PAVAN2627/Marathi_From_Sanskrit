Project Objectives
Design a hybrid architecture integrating rule-based phonology with Transformer neural modelling
Formally encode Sanskrit–Marathi phonological & morphological transformation rules (vowel shifts, schwa deletion, assimilation)
Develop phoneme-level modelling using IPA-based feature embeddings for structural sound-change learning
Construct a curated, aligned Sanskrit–Marathi diachronic lexical dataset
Model semantic drift between Sanskrit roots and Marathi derivatives using embedding-based similarity
Implement an explainability module generating interpretable, step-wise phonological transformation outputs
Evaluate using CER, Phonetic Edit Distance, BLEU/chrF scores + expert linguistic validation
Release an open-source computational historical linguistics toolkit for Marathi

--- ppt/slides/slide5.xml ---
Proposed System Architecture
1
Linguistic Rule Encoding Layer
Formal computational encoding of historical phonological rules: vowel shifts, consonant simplification, schwa deletion, assimilation, morphophonemic alternations
2
Phoneme-Level Neural Modelling
Transformer architecture trained at phoneme level with IPA-based feature embeddings — learns structural phonetic evolution patterns, not surface orthography
3
Semantic Drift Modelling Layer
Contrastive representation learning captures semantic proximity and gradual meaning shifts between Sanskrit roots and Marathi derivatives
4
Explainability & Traceability Module
Generates interpretable step-wise transformation outputs showing intermediate phonological stages — transparent, not opaque neural predictions
INPUT: Sanskrit Root
OUTPUT: Reconstructed Marathi Form + Transformation Trace
